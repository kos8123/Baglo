Branch policy

  • dev is the integration branch
  • main represents production
  • Feature branches are short-lived
  • Direct production changes are avoided

Pull request evidence

  • Purpose and affected components
  • Test results and screenshots
  • Infrastructure and cost impact
  • Known limitations and rollback plan

Secret handling

  • Never commit API keys
  • Use AWS Secrets Manager
  • Use deployment variables for public config
  • Rotate exposed credentials immediately
