# React 版操作驗收

開啟 http://127.0.0.1:8000/ 後重新整理。以下由使用者操作驗收；本次沒有代跑瀏覽器測試。請回報「編號、操作、預期、實際」，可附截圖。

| # | 操作 | 預期 |
|---|---|---|
| 1 | 桌機全螢幕、縮至約 900px、手機約 390px | 面板不互相覆蓋，整頁不橫向溢出；長表格在區塊內捲動。手機可找到 K 線、下單、持倉與標的清單。 |
| 2 | 搜尋 2330、台積電、臺積電、6488、環球晶 | 選取結果後，圖表、下單與研究皆為同一股票；選錯或只輸入未選取時不得下單。 |
| 3 | 用最低／最高價格篩選；清除；鍵盤上下、Enter、Escape | 篩選以收盤價為準，清除可重搜，Escape 保留原標的；無結果或資料錯誤有提示。 |
| 4 | 整股／零股切換 | 使用不同市場報價；整股輸入張、零股輸入股；1 張顯示 1,000 股。兩種數量草稿保留。 |
| 5 | 修改限價，再按「更新」；按「帶入報價」 | 更新不覆蓋自訂限價；帶入報價才覆蓋。休市價格明示日期，沒有冒充現價。 |
| 6 | 限價按 ＋／−，在 10、50、100、500、1,000 元邊界檢查 | 依股票升降單位調整；超出漲跌停或缺少有效資料時不得送出。 |
| 7 | 買進超過原本 6 萬元、但含費用不超過可用資金 | 不再因單筆金額上限拒絕；超過可用資金仍拒絕。先用適合資金的普通股驗證。 |
| 8 | 點買進／賣出，檢查確認視窗；按返回、Escape、外部遮罩 | 方向、股數、限價、費用、稅與總額正確；取消確認不新增委託。 |
| 9 | 確認送單，快速重複點擊 | 僅一筆委託，待送出時按鈕停用。顯示「請至委託紀錄查詢」，點擊可到紀錄；送出不代表成交。 |
| 10 | 取消待成交委託 | 狀態改為已取消，保留資金／股數釋放；刷新頁面仍保留帳本。 |
| 11 | 本機委託後點「沙盒成交」，再測賣出與持倉不足 | 依限價完成純帳務示範，費稅入帳；賣出不得超過可賣股數；整股零股共用持倉。這不代表行情撮合。 |
| 12 | K 線左右移動、上下移動、拖曳、滾輪／手勢、＋／−、重設、全部歷史 | 十字線吸附 K 棒收盤價，同根上下移動不改價格；開高低收與成交量正確，拖曳縮放可操作，重設回預設範圍。 |
| 13 | 日 K／週 K／月 K 切換，載入更早資料 | 顯示對應週期；週線以週一分組，月線以曆月分組。歷史逐批擴至近三年，手動最多十年，缺漏不補造。首末期間可能不完整。 |
| 14 | 快速切換不同股票後返回 | 不出現舊股票覆蓋新股票的圖表、研究或報價；載入失敗可重試，現有資料不虛構。 |
| 15 | 開啟個股研究 | SMA20/60、營收年／月增、本益比、股價淨值比、殖利率與法人買賣超有資料日期；缺資料顯示 —，不當成 0。 |
| 16 | 委託紀錄切換全部／待成交／已成交／已取消 | 篩選正確；底部委託與主委託頁同步；既有舊版委託仍可讀。 |
| 17 | 日後 AWS 部署後測登入、登出、失效 token（本機不適用） | Cognito PKCE 登入後才能讀帳戶；不同使用者隔離，失效後停用下單；正式版不得出現沙盒成交操作。 |
| 18 | 網路中斷／後端暫停後更新報價或委託 | 顯示錯誤；委託不自動重試。恢復後同內容重試沿用請求編號，不重複寫入。 |

AWS 自動部署仍需先完成 repository variables、OIDC 角色與 bootstrap。這次完成程式與工作流程遷移，不表示已在 AWS 部署成功。

## 本次修正優先驗收

1. 只看到左側導覽，手機也能用；頂部不再有第二排功能按鈕。
2. 輸入台積電、臺積電或 2330，唯一精確結果自動選定後按買進，不再要求重新搜尋；模糊且多筆結果仍需選取。
3. 送出前確認可用資金包含待成交保留與費用。下單後查紀錄；若回應中斷但帳本已有同一請求編號，應回報受理，不能重複建單。狀態無法確認時應顯示「未能確認」，而不是直接宣稱失敗。
4. 左側「我的持倉」可看可賣股數、平均成本、參考價、市值、損益與報酬率。只有已成交委託進入持倉，待成交不列庫存。
5. 左側 Swagger 開啟文件；本機可讀健康檢查與帳戶，所有價格欄位單位為分。不要在文件輸入 OpenAI／富果金鑰。
6. AI 無模型金鑰時明示待設定，不顯示假建議。設定後可分析來源支援的目前上市櫃普通股、查看非同步工作與三面向理由；採用建議需再次確認。這會消耗模型額度。
7. 非交易時段採用 AI 建議應被攔截；設定自動模擬不代表本機已架每日排程，AWS 全部尚未部署。

8. AI 自動標的池搜尋加入 6488 環球晶或其他原六檔以外的普通股，儲存後重整仍保留；可移除、加入目前股票。原六檔以外的推薦分析不再被按鈕或後端白名單攔截。
